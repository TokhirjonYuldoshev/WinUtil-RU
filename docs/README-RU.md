# WinUtil RU: руководство по русской редакции

Эта страница относится к [TokhirjonYuldoshev/WinUtil-RU](https://github.com/TokhirjonYuldoshev/WinUtil-RU). Документационный сайт в `docs/src/content/docs/` унаследован от оригинального WinUtil: он описывает исходный проект и местами содержит команду запуска оригинала. Для русской редакции используйте команды и ссылки ниже.

## Что это за программа

[WinUtil](https://github.com/ChrisTitusTech/winutil) — утилита для Windows с графическим интерфейсом PowerShell/WPF. В ней можно устанавливать программы через WinGet или Chocolatey, выбирать настройки Windows, управлять компонентами и приложениями AppX, открывать системные инструменты, менять режим обновлений и работать с ISO Windows 11. Эти действия меняют систему только после выбора соответствующей команды; состав доступных операций определяется исходным проектом и выбранным выпуском.

**WinUtil RU** — независимая русская редакция на базе выпуска оригинала `26.08.19` (исходный commit [`086aecf4b7d165f9fd1822049435c418a48e7cba`](https://github.com/ChrisTitusTech/winutil/commit/086aecf4b7d165f9fd1822049435c418a48e7cba)). В этой редакции изменены видимые тексты интерфейса, переключение языков, заставка YTY и информация «О программе»; предусмотрены сборка и загрузчик русского выпуска. Логика установки, твиков, AppX, обновлений и работы с ISO взята из указанного оригинального выпуска. Названия продуктов, пути реестра, внутренние идентификаторы, отдельные технические сообщения и вывод сторонних инструментов могут оставаться английскими: их перевод может нарушить исходные действия.

Это форк, а не официальный русскоязычный выпуск Chris Titus Tech. Разработчик русской редакции не является автором исходных функций WinUtil.

## Запуск и смена языка

1. В Windows откройте PowerShell или Windows Terminal **от имени администратора**.
2. Запустите загрузчик стабильной ветки:

   ```powershell
   irm https://raw.githubusercontent.com/TokhirjonYuldoshev/WinUtil-RU/russian/bootstrap.ps1 | iex
   ```

   Команда получает и исполняет удалённый сценарий. Перед выполнением можно [просмотреть исходный код загрузчика](https://github.com/TokhirjonYuldoshev/WinUtil-RU/blob/russian/bootstrap.ps1).

3. Если удобнее запускать проверенный вами файл, скачайте `winutil-RU.ps1` из [стабильного релиза](https://github.com/TokhirjonYuldoshev/WinUtil-RU/releases/latest) и выполните в каталоге с файлом:

   ```powershell
   powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\winutil-RU.ps1
   ```

Русский язык выбран по умолчанию. Для смены языка откройте меню с шестерёнкой, выберите **English** или **Русский**, затем перезапустите программу. Пункт **«О программе»** находится в том же меню. Выбор языка хранится для текущей учётной записи Windows; он меняет только отображение, а не состав применяемых действий.

## Что сделано в русской редакции

| Область | Результат |
| --- | --- |
| Вкладки «Установка», «Настройки», «Инструменты», «Обновления», Windows 11 и AppX | Пользовательские подписи, описания и основные сообщения доступны по-русски; в меню есть переключение на английский. |
| Запуск и авторство | Показана заставка YTY с именем Tokhirjon Yuldoshev; окно «О программе» сохраняет сведения об оригинальных участниках и указывает переводчика. |
| Выпуск | Стабильная ветка `russian`, PowerShell-загрузчик и выпуск `winutil-RU.ps1` с файлом `release.json` и копией `LICENSE`. |
| Функции | Исходные обработчики WinUtil и машинные значения сохранены по сравнению с базовым выпуском `26.08.19`; новые тексты относятся к представлению. |

Наличие галочки возле настройки означает **выбор действия**, а не подтверждение его успешного выполнения. После запуска операции смотрите итоговое сообщение и журнал: завершение с предупреждением или ошибкой может означать, что часть действий уже применена. Журналы сеансов записываются в `%LocalAppData%\winutil\logs\winutil_*.log` (обычно `C:\Users\<имя>\AppData\Local\winutil\logs\`). Для анализа ошибки укажите время, название операции и соответствующие строки журнала, предварительно скрыв личные данные.

## Обновления и что делать владельцу проекта

На текущий проверенный базовый выпуск `26.08.19` русская редакция уже собрана и опубликована. Для повседневного запуска дополнительных действий не требуется. При следующем выпуске оригинала порядок такой:

1. Автоматическое отслеживание ищет новый выпуск оригинала и подготавливает кандидата на обновление. Оно не делает новый русский релиз доступным пользователям самостоятельно.
2. Сверить кандидата с точным исходным тегом, проверить различия, сборку, тесты и сохранность исходных обработчиков; обновить перевод новых элементов.
3. На Windows вручную проверить вкладки и переключение языка; действия, меняющие систему, испытывать на тестовой машине и записывать проблемы по журналу.
4. После проверки принять изменения в стабильную ветку `russian`. Публикация стабильного релиза запускается GitHub Actions при **каждом** push в `russian`, включая изменение одной лишь документации. Перед слиянием запросов убедитесь, что согласны с перепубликацией текущей версии.

Ветка `main` синхронизируется с исходным проектом, `russian` содержит стабильную русскую редакцию, `russian-dev` — отдельную ветку для проверки. Используйте [раздел Releases](https://github.com/TokhirjonYuldoshev/WinUtil-RU/releases), чтобы увидеть текущий опубликованный файл; более новые изменения в `main` сами по себе не обновляют стабильный русский выпуск. Загрузчик стабильной ветки может заново скачать исходники и пересобрать локальный кеш при смене версии или commit, поэтому после обновления выпуск проверяют как через загрузчик, так и через опубликованный файл.

## Исходники и проверка изменений

Рабочий код расположен в `functions/`, `config/`, `scripts/` и `xaml/`. `Compile.ps1` собирает из них единый PowerShell-файл; `winutil.ps1` является создаваемым результатом сборки и не редактируется вручную. Файл `SPEC.md` описывает архитектуру, `AGENTS.md` — правила работы с кодом. Для проверки изменений в интерфейсе сравнивайте ветку `russian` с тем же исходным выпуском оригинала: перевод должен менять видимые тексты и выбор языка, не значения команд и обработчиков. Проверки GitHub Actions помогают обнаружить ошибки сборки и тестов, но не заменяют ручную проверку Windows GUI.

Документационный сайт оригинала находится в [`docs/src/content/docs/`](src/content/docs/). Он остаётся документацией оригинального проекта и не должен рассматриваться как переведённая инструкция по запуску форка. Генерируемые справочные страницы сайта не редактируют вручную.
